# Hazard mapping setup

Based on LGA BDRRM Plan and Committee Technical Guide Notes, items 5 and 7.1 (https://cdn.lga.gov.ph/publication/attachments/1704791931.pdf). Hazard maps must come from C/MPDO, C/MDRRMO or an appropriate authoritative source. HazardHunterPH is linked for source assessment, not embedded or scraped as a public tile service.

The migration `2026_10_20_000002_create_mapping_hazard_layers.php` creates persistent, barangay-scoped planning layers. Apply it on deployment with `php artisan migrate --path=database/migrations/2026_10_20_000002_create_mapping_hazard_layers.php`.

Open Mapping > Hazard planning. The panel opens automatically. Use Fit hazard map to bring all filtered hazard features into view. A Chairperson, Operations/Admin, Mitigation and Prevention, or Preparedness account with Geospatial Analytics access can download the template and import official packages. Existing web module permissions apply; writes additionally require the `manage_hazards` permission, which is granted to `chair`, `operations_admin`, `mitigation_prevention`, and `preparedness` roles. The setup is available without an active disaster. Each hazard has independent coverage indicators for mapped areas, designated centers and reviewed evacuation routes.

Packages have `name`, `source`, optional `source_url` (HTTP/S), `assessed_at` and `geojson` (FeatureCollection). Every feature requires properties `kind`, `name`, `hazard_type`, `risk_level` (low/medium/high), `purok_id`, `reviewed_by`. Use real registered purok IDs from the map filter. Coordinates are WGS84 longitude, latitude. Hazard areas use closed Polygon or MultiPolygon rings; centers use Point; reviewed routes use LineString and must include `properties.destination` identifying their center. Supply optional nonnegative `individuals` and `families` counts for hazard areas. Missing counts remain unknown, rather than zero.

Use separate assessed features for each purok/sitio and hazard/risk category. Exposure counts are supplied by the assessing office; they are not automatically inferred from active-event household markers. Overlapping areas and different hazards are not summed. Administrative imports preserve source, reviewer and assessment date. Imported routes represent the reviewer's assessment and are not automatically certified safe by the routing engine. Refresh official assessments when conditions change.

Export a package for revision, then import the revision and remove its superseded package. Mambaling now ships with real MGB flood susceptibility imagery and PHIVOLCS liquefaction polygons from GeoRisk, retrieved 2026-10-20. These load automatically; no import is required. See MAMBALING_HAZARD_SOURCES.md for provenance. No evacuation routes are fabricated. Operational dispatch routes remain distinct from reviewed evacuation routes.
