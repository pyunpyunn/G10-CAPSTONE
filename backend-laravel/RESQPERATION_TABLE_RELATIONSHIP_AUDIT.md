## Finding and scope

The earlier statement that all missing history-table FKs were intentional was too broad. Several real parent references remain unenforced. Zero pending statements in the existing repair plan means that its declared relationships are satisfied; it does not prove complete relationship coverage. The ERD is not finalized.

Every genuine entity reference needs an explicit integrity strategy. Every table does not need an artificial foreign key. Lookup parents may have only incoming relationships; independent queues/caches/configuration can be standalone; polymorphic recovery/archive references require application validation and snapshots. Eloquent belongsTo definitions do not create physical SQL foreign keys, which MySQL Workbench draws.

This inventory covers all 63 canonical Resqperation operational tables in config/resq_database.php. The retained team_bases compatibility table is addressed separately. Shared users/households/geography/request/auth tables are dependencies, not Resq-owned tables. The remaining shared database tables are not silently classified as ours. A fresh full-schema ownership reconciliation remains necessary when Klint reconnects. No EvaTrack/BIDRCS-only changes are proposed.

## Additional schema mismatch discovered

The saved rescue_criteria_snapshots columns do not include definition_version. RescueCriteriaQuery::timeline/persistPoint and RescueCriteriaHistoryQuery::refresh read/write definition_version = 6. Migration 2026_10_04_000007_version_rescue_criteria_snapshots.php defines it, but a guarded create-table reconciliation does not guarantee later upgrades ran. This can break criteria history/charts despite green fixture-based tests. A new idempotent scoped repair, 2026_10_30_000002_reconcile_rescue_criteria_definition_version.php, adds only the missing column and preserves old rows as version 1. The Eloquent model now maps definition_version and both criteria models map their disaster/settings parents. The repair passes an isolated imported-schema regression test but has not been applied to Klint. Recheck live columns and test the actual criteria endpoint after applying it. Do not label the live issue fixed yet.
